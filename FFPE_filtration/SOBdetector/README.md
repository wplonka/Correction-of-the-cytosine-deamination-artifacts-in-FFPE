
# SOBDetector VCF Filtering Pipeline

## Overview
This script performs filtering of VCF files using classification results generated by SOBDetector. 

## Input Data
- VCF files generated by SOBDetector

## Requirements
* R (>=4.1 recommended)
  
## Required R packages
* VariantAnnotation
* openxlsx

## Output
* Filtered VCF files
* Summary table (removed vs remaining variants)
