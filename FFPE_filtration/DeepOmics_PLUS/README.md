## Overview
We used the on-premise version of DeepOmics FFPE-Plus. This tool is not yet publicly available and was made accessible through our initial collaboration with DeepOmics.

We would like to thank Inyoung Kim (Theragen Bio) for performing the DeepOmics FFPE-Plus analyses.

## DeepOmics_Plus_vcf_filter.R
This script filters FFPE artifacts from VCF files generated by DeepOmics FFPE Plus. It is designed to detect and remove variants likely caused by FFPE sample processing, providing cleaner variant calls for downstream analysis.

## Requirements
* R (>=4.1 recommended)
  
## Required R packages
* VariantAnnotation
* openxlsx

## Output
* Filtered VCF files
* Summary table (removed vs remaining variants)
