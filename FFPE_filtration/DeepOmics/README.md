## Overview
DeepOmics is publicly available as a web service:  
https://www.deepomics.co.kr/ffpe/run

In this project, however, the analyses were not performed using the online interface.  
We used the on-premise version of both DeepOmics and DeepOmics FFPE-Plus.

We would like to thank Inyoung Kim (Theragen Bio) for conducting the DeepOmics and DeepOmics FFPE-Plus analyses.

## DeepOmics_vcf_filter.R
This script filters FFPE artifacts from VCF files generated by DeepOmics FFPE. It is designed to detect and remove variants likely caused by FFPE sample processing, providing cleaner variant calls for downstream analysis.

## Requirements
* R (>=4.1 recommended)
  
## Required R packages
* VariantAnnotation
* openxlsx

## Output
* Filtered VCF files
* Summary table (removed vs remaining variants)
